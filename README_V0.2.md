# Hisense Dashboard V0.2

Site statique pour le navigateur VIDAA. Aucun root, flash ou serveur domestique nécessaire.

## Nouveautés
- Navigation spatiale avec flèches de la télécommande, OK/Entrée pour ouvrir.
- Quatre favoris personnalisables et réordonnables dans Paramètres.
- Météo de la ville choisie, actualisée toutes les 30 minutes.
- Horloge/date locales, raccourci Jellyfin web facultatif.
- Paramètres et favoris conservés dans le stockage local du navigateur (si autorisé).

## Installation GitHub Pages
Remplacer le fichier `index.html` à la **racine** du dépôt GitHub Pages existant par celui de cette archive, puis valider (`Commit changes`). Conserver Settings > Pages > main > /(root). Rafraîchir la page TV après publication; si l'ancienne version reste affichée, fermer puis rouvrir le navigateur.

## Limites
Les liens Netflix, YouTube, Prime Video et Disney+ ouvrent des sites web, qui peuvent ne pas fonctionner dans le navigateur VIDAA. Pas de lancement d'app native, pas de commande HDMI, pas de remplacement de la touche HOME. Jellyfin requiert un serveur accessible. Open-Meteo requiert Internet. Selon le navigateur, le stockage local et les boîtes de dialogue peuvent varier.
